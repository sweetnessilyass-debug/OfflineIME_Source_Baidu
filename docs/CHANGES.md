# 0.2 修改记录

## 输入与离线语音

- 保留原有九宫格、拼音、词库和候选处理核心。
- 固定内置普通话离线模型和 ARM64 解码库；用校验值确定资源版本。
- 在核心初始化边界传入局部兼容元数据，修复重签后候选异常；不修改系统包管理器或实际 APK 签名。
- 移除联网权限，对已识别的网络入口使用可被原代码处理的离线失败路径，避免无联网权限异常导致自行退出。

## 商业入口

- 工具栏保留四项本地功能，关闭独立 AI 按钮及动态追加。
- 主菜单使用本地功能清单，移除账号、会员与推荐页头。
- 停用 17 项非必要启动回调，禁用 362 个相关组件声明，移除 57 项权限声明。
- 关闭商业插件云控任务和菜单动态分发更新。
- 剪贴板移除云同步、在线推荐和条目联网搜索/翻译；保留本地内容搜索。
- 修复云同步残留按钮尝试打开已禁用登录页导致的闪退。
- 修复关闭 AI 字体初始化后的观察者异常，以及菜单图标依赖皮肤资源导致的空位图异常。

## 本地设置

- 本地首页提供输入法启用、切换、麦克风授权、试打和输入设置入口。
- 输入和键盘设置复用原版偏好保存与变更逻辑，按页面移除已识别的在线项。
- 设置范围与测试结果以 README 的当前说明为准，不声称全部原版功能可用。

## 验证边界

单台 Android 13 / ARM64 开发设备完成常用打字、人工普通话短句与部分设置页面测试。候选、语音和后续页面修复由不同开发构建分别验证。尚未完成多机型、全新安装、长时间稳定性和全部隐藏入口测试。

公开源码不附设备日志、截图、输入记录或个人数据库。每个发布 APK 需单独给出构建校验和对应实测范围。
