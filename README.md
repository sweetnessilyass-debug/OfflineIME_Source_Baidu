## ✂️ 都给它减了什么？

| 部门 | 本次安排 |
| --- | --- |
| 九宫格、拼音、候选词 | 保留原有本地输入核心；没有重写拼音算法和词库 |
| 语音输入 | 内置普通话模型与 ARM64 解码库，固定走离线识别 |
| 网络 | 移除 `INTERNET` 权限，并处理已发现的联网初始化异常 |
| 键盘工具栏 | 保留语音、剪贴板、文本编辑和输入方式；独立 AI 按钮退场 |
| 键盘主菜单 | 保留 13 项本地功能，包含设置入口；去掉账号、会员和运营内容区 |
| 商城、广告、推送等 | 禁用 362 个相关组件声明，停用 17 项非必要启动回调 |
| 权限 | 删除 57 项声明，保留 15 项本地输入及框架兼容权限 |
| 剪贴板 | 去掉云同步、在线推荐和条目联网搜索/翻译，保留本地内容搜索与设置 |
| 首页和系统设置入口 | 本地首页提供启用、切换、授权和试打；系统设置入口恢复原有本地输入设置 |
| 调试功能 | 默认关闭；诊断包需要显式使用 `--debug` 构建 |

13 项本地菜单：**语音、剪贴板、编辑、输入方式、面板高度、日夜模式、音效与振动、振动调节、单双手模式、简繁转换、悬浮键盘、设置、收起键盘**。

模糊音、拼音纠错、双拼和键盘操作习惯入口已恢复，沿用原有偏好保存逻辑。设置页移除已识别的云输入、推荐和商业跳转项，尚未逐项验证所有高级选项。

精简主要通过入口关闭、组件禁用和流程调整实现。原厂部分代码和资源仍保留在包内，未穷举每个隐藏入口。这里的“精简”是功能减负，不能自动兑换成“每一行代码都审计过”。

## 🎙️ 没网，语音怎么上班？

模型和解码库随构建一起打包，首次启动在手机本地准备资源，不需要临时联网下载。

- 当前目标是普通话短句识别与上屏。
- 录音仍需手动授权麦克风。离线不是读心术，该开口还是得开口。
- 识别路径固定为离线模式，没有在线识别兜底。
- 不依赖复制个人手机数据库或登录账号来准备资源。
- 模型会增加安装包与安装后的存储占用。网络线剪掉了，行李还得自己带。

方言、多语言、强噪声、长句、专有名词和长期功耗没有充分测试，也不承诺与在线识别相同的效果。

## 🚀 安装后，三分钟开工

本项目使用独立签名，通常不能覆盖安装原版百度输入法；更换签名可能需要卸载旧版本，卸载会清除其设置、本地学习数据等。请先确认要保留的数据。

拿到对应发布版本的 APK 后：

1. 确认设备为 **ARM64**，核对安装包校验值。
2. 打开本地首页，启用并切换到“百度离线输入”。
3. 等待内置语音资源准备完成，先在试打区试试普通输入。
4. 需要语音时，授权麦克风，点击键盘上的麦克风说一句普通话。
5. 键盘左上角菜单 → **更多设置**，或首页 → **输入与键盘设置**：
   - 模糊音：**输入设置 → 模糊音**。
   - 布局：**键盘界面设置 → 键盘布局**，提供新版、经典、双键布局。
   - 上滑字符、左右滑动、按下气泡等习惯：**键盘界面设置**。

首次准备模型需要一点时间。键盘正在搬家，不一定是在装死。

## 🧪 已经测了哪些？

开发阶段在 **单台 Android 13 / ARM64 设备**上验证了：

- 九宫格输入、中文候选显示与选择上屏。
- 人工普通话短句识别与上屏。
- 主菜单显示、工具栏精简和独立 AI 按钮移除。
- 剪贴板云同步按钮移除、本地搜索和设置页打开。
- 常规构建冷启动、系统输入法设置入口跳转。
- 恢复设置后的诊断构建：模糊音开关保存、经典与新版布局切换；测试后恢复原值。
- 安装包签名、ZIP 对齐、联网权限移除和原始资源一致性。

语音与候选完整手动测试来自此前清理诊断包；剪贴板补修后的常规包完成了启动与相关页面检查，设置恢复后的诊断包完成了开关保存和布局切换测试，最终常规包另做启动检查，**没有再次录音复测**。相关核心和模型未变。不同构建的验证结果分别记录，不能混成“每个包都全测过”。

多机型、全新安装流程、长时间运行、连续录音和少见入口仍需验证。一次短句成功，暂时不能晋升“全宇宙输入法冠军”。

## 🙋 几个直球问题

**还有登录、云同步和皮肤商城吗？**

这些在线功能不在当前版本支持范围内。已识别入口关闭，应用也不申请联网权限。

**为什么修了剪贴板云同步闪退？**

因为登录页已经下班，剪贴板里却还留着叫它上班的按钮。现已同时移除按钮和相关调用。具体改动见 [更新记录](docs/CHANGES.md)。

**这是不是百度输入法完整源码？**

仓库中是本项目的补丁脚本与辅助代码。厂商 APK、模型、词库和原有代码的权利归各自权利人，详见 [第三方内容说明](NOTICE.md)。

**怎么反馈问题？**

Issue 里写明系统版本、构建版本、操作步骤和实际现象即可。使用无隐私的测试文字，截图和日志请先遮掉账号、聊天内容、通知、个人路径及设备标识。
